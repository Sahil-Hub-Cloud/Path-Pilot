# Security Policy

## Responsible Disclosure
If you discover a vulnerability, please report it via email to **security@pathpilot.app**.
We aim to acknowledge reports within **24 hours**.
Critical vulnerabilities will be patched within **7 days**.

## Bug Bounty
While we are pre-funding, we offer:
- $100-$500 in Swag
- Hall of Fame recognition
- Cash bounties enabled post-Series A

## Incident Response
1. **Detection**: Automated alerts from Cloudflare/Vercel or User Report.
2. **Containment**: Rotate keys, revoke compromised sessions.
3. **Eradication**: Patch vulnerability, deploy fix.
4. **Recovery**: Verify system integrity, restore service.
5. **Post-Mortem**: Publish transparency report if user data was affected.
